# 까치녹음기 설치 안내 (여자친구 맥에서)

걸리는 시간: **30~40분**. 대부분 모델(약 4GB)을 받는 시간이다.
준비물: 충전기, 빠른 와이파이, 실제 강의 녹음 파일 1~2개 (한·영 섞인 것이 있으면 가장 좋음).

---

## 0. 시작 전 확인 (2분)
- [ ] 사과 메뉴 › 이 Mac에 관하여 → 칩이 **Apple M1 이상**인지, 메모리가 몇 GB인지 확인
- [ ] 저장 공간이 **10GB 이상** 남았는지 확인 (시스템 설정 › 일반 › 저장 공간)
- [ ] 충전기 연결

## 1. 코드 받기 (3분)
터미널(⌘+Space → "터미널")을 열고:

```bash
git clone https://github.com/kimdoyoung1110/kkachi-nogeumgi.git ~/까치녹음기
```

- "명령어 개발자 도구를 설치하시겠습니까?" 창이 뜨면 **설치**를 누르고, 끝난 뒤 위 명령을 다시 실행
- 이 폴더(`~/까치녹음기`)는 **옮기거나 지우면 안 된다** (앱이 이 폴더를 사용함)

## 2. 설치 (20~30분)
```bash
open ~/까치녹음기
```
Finder 에서 **`설치.command`** 를 두 번 누른다.
- "확인되지 않은 개발자" 경고가 뜨면: 파일을 **우클릭 › 열기 › 열기**
- 진행 단계: `0/5 확인 → 1/5 uv → 2/5 라이브러리 → 3/5 모델 4GB → 4/5 시험 받아쓰기 → 5/5 앱 만들기`
- `4/5` 에서 `✓ 시험 받아쓰기 성공` 이 나와야 한다. 이때 표시되는 **"28초 음성 처리 N초"** 를 기록해 두기 (속도 기준)
- 끝나면 응용 프로그램 폴더가 열리고 까치녹음기가 켜진다

## 2-1. 🎁 선물 설정 (여자친구 몰래, 1분)
설치가 끝나고 **앱을 켜기 전에** 터미널에서:

```bash
cd ~/까치녹음기 && .venv/bin/python -m app.gift
```
- 이름(애칭) → 보내는 사람 이름 → 편지 내용 순서로 물어본다. 편지는 여러 줄 가능, 다 쓰면 빈 줄에서 Enter 두 번
- 저장 위치는 이 맥의 `~/Library/Application Support/KkachiNogeumgi/gift.json` (GitHub 에 올라가지 않음)
- 효과: 화면 이름이 "○○의 까치녹음기"로, 시간대별 인사, **처음 켤 때 사용법 안내 마지막 장에 편지** (⚙ › 편지 다시 보기)
- 확인: `.venv/bin/python -m app.gift --show` / 지우기: `--clear`
- 편지 내용을 나중에 바꾸면 다음 실행 때 한 번 더 뜬다

## 3. Dock 에 올리기 (1분)
- [ ] 응용 프로그램 폴더의 **까치녹음기**를 Dock 으로 끌어다 놓기
- [ ] **까치녹음기 창**이 열리고 **사용법 안내 3장**(+ 편지)이 뜨는지 확인
- [ ] "알림을 허용하시겠습니까?" 창이 뜨면 **허용** (받아쓰기 끝남·배터리·무음 알림)
- 창의 빨간 닫기 버튼은 창만 숨긴다 (앱·녹음은 계속). Dock 아이콘을 누르면 같은 창이 다시 나온다. 완전히 끄는 건 ⌘Q
- 메뉴 › 까치녹음기 › **브라우저에서 열기**(⌘⇧O)로 크롬·사파리에서도 열 수 있다

## 4. 현장 확인 목록 (10분) — 여기가 Step 9 의 핵심

### 4-1. 녹음 (앱 창에서)
- [ ] **● 녹음하기** → "까치녹음기이(가) 마이크에 접근하려고 합니다" 창에서 **허용**
  - 허용 창이 안 뜨거나 막히면: 시스템 설정 › 개인정보 보호 및 보안 › 마이크 › **까치녹음기** 켜기
  - 실행기가 바뀌는 업데이트 뒤에는 이 허용 창이 한 번 더 뜰 수 있다
- [ ] 소리 크기 막대가 말할 때 움직이는지
- [ ] 30초 정도 말하기 (중간에 일시정지 → 계속 한 번)
- [ ] "00:20까지 안전하게 저장됨" 표시가 올라가는지
- [ ] 녹음 끝내기 → 받아쓰기 시작 → **완료 후 결과가 맞게 나오는지, 재생바로 앞뒤 이동이 되는지**
  - 앱 창은 크롬과 같은 형식(webm)으로 녹음한다 (로그로 확인됨). 실제 마이크 녹음은 여기서 처음 확인
- [ ] 결과 화면 **내보내기 › 텍스트** → 다운로드 폴더에 저장되고 Finder 에서 보이는지

- [ ] 녹음 중 **스페이스바**(또는 ⭐ 중요! 버튼) → 결과에서 그 문단에 ⭐, "⭐ 중요만" 필터
- [ ] 충전기를 빼고 녹음하면 🔌 경고가 보이는지

### 4-2. 실제 강의 파일
- [ ] 실제 강의 녹음(10분 이상)을 끌어다 놓고 **한·영 섞임(자동)** 으로 받아쓰기
- [ ] 걸린 시간 기록: ____분 (녹음 ____분)
- [ ] 확인할 것
  - 교수님/학생이 다른 화자로 나뉘는지
  - 영어 문장이 **번역되지 않고** 영어로 적히는지
  - 영어 전문 용어가 한글로 적히는 경우가 많은지 (예: 컬리전) → 많으면 그 과목에 **용어 바꾸기** 등록
- [ ] 화자 이름을 "교수님"으로 바꿔보기, 문장 하나 고쳐보기, 검색해보기

### 4-3. 앱 켜고 끄기
- [ ] ⌘Q 로 끄기 → Dock 아이콘 다시 눌러 켜기 → 화면이 다시 열리는지
- [ ] ⚙ › 업데이트 확인 → "지금이 최신 버전이에요"
- [ ] ⚙ › 문제 신고용 로그 저장 → 바탕화면에 zip 이 생기는지 (확인 후 지워도 됨)

### 4-4. 여자친구에게 알려줄 것 (2분)
- 강의 시작할 때 Dock 의 까치녹음기 → **● 녹음하기**
- **맥북 뚜껑 닫지 않기**, 충전기 꽂아두기
- 끝나면 녹음 끝내기 → 과목 적고 받아쓰기 시작 → 기다리는 동안 다른 거 해도 됨
- 이상하면 ⚙ › 문제 신고용 로그 저장 → 바탕화면 zip 을 카톡으로

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `설치.command` 가 "애플 실리콘…" 으로 멈춤 | 인텔 맥이라 사용 불가 |
| 3/5 에서 "모델을 받지 못했어요" | 와이파이 확인 후 `설치.command` 다시 실행 (받은 부분은 이어서 받음) |
| 4/5 시험 받아쓰기 실패 | 터미널 화면을 사진으로 찍어 확인. 보통 메모리 부족 → 다른 앱 끄고 재실행 |
| 앱을 눌렀는데 "설치를 찾을 수 없어요" | `~/까치녹음기` 폴더가 옮겨짐 → 원래 자리로 되돌리거나 다시 clone + 설치 |
| 앱을 눌렀는데 "다른 프로그램이 8765번 통로를…" | 맥 재시동 |
| 화면에 "앱과 연결이 끊겼어요" | Dock 의 까치녹음기 누르기 |
| 받아쓰기가 너무 느림 | 메모리 부족(스왑) 가능성 → 크롬 탭·다른 앱 닫기. 로그 zip 의 기기정보 확인 |
| 녹음 버튼을 눌러도 아무 반응 없음 | 마이크 권한 (4-1 참고). 그래도 안 되면 메뉴 › 브라우저에서 열기 로 녹음 |
| 업데이트가 "인터넷 연결을 확인" 이라고 함 | 와이파이 확인. 계속되면 `~/까치녹음기/설치.command` 다시 실행 (= 업데이트) |

### 로그 위치
- `~/Library/Application Support/KkachiNogeumgi/logs/` (`kkachi.log`, `server.log`)
- 녹음·DB 도 같은 폴더(`recordings/`, `kkachi.db`). 백업하려면 이 폴더째 복사

### 완전히 지우기
1. 까치녹음기 끄기 (⌘Q)
2. 응용 프로그램의 까치녹음기 휴지통으로
3. `~/까치녹음기` 폴더 휴지통으로
4. (녹음까지 지우려면) `~/Library/Application Support/KkachiNogeumgi` 휴지통으로
5. (모델 4GB 까지 지우려면) `~/.cache/huggingface` 안의 `models--mlx-community--*`, `models--beshkenadze--*`
